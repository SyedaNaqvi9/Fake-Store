Fake Store

A responsive e-commerce web application built with React. Users can browse products, search by title, filter by category, sort by price, view product details, and manage a shopping cart.

Live Demo

https://syedanaqvi9.github.io/Fake-Store/

Features
Browse products from the Fake Store API
Search products by title
Filter products by category
Sort products by price (Low to High / High to Low)
View detailed product information
Add and remove products from cart
Persist cart data using Local Storage
Responsive design for desktop and mobile devices
Technologies Used
React
React Router
JavaScript (ES6+)
HTML5
CSS3
Vite
Fake Store API
Installation
Clone the repository
git clone https://github.com/syedanaqvi9/Fake-Store.git
Install dependencies
npm install
Start the development server
npm run dev
